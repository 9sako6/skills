# 例: 画面の要素

デザインの共有リンクで、設定画面の案をレビューした場合:

````markdown
設定画面の案（https://design.example.com/settings 、版 3）を、後続の計画（通知の設定項目の追加）と突き合わせて見ました。試作の操作はしていません。

## Findings

### 1. Medium: 保存の操作を、設定項目ごとに持たせている

**Before**

```text
後続の計画で、通知の設定項目を 3 つ足すとき
画面: [表示名 ____ 保存] [メール ____ 保存] [言語 ▼ 保存] …項目ごとに保存ボタン
→ 足す項目ごとに保存ボタンと、保存できたときの表示と、失敗したときの表示を作る
```

**After**

```text
後続の計画で、通知の設定項目を 3 つ足すとき
画面: [表示名 ____] [メール ____] [言語 ▼] … 画面の下に [保存] が 1 つ。変えた項目には印
→ 項目の欄だけを足す
```

- **箇所**：
  - 保存ボタン: 設定画面 > プロフィール（https://design.example.com/settings 、版 3）
  - 通知の設定項目の追加: 後続の計画 > 通知（https://wiki.example.com/plan/notifications）
- **うれしさ**：項目を足す人は、保存の表示を作り直さずに済む。利用者は、どの項目を保存し忘れたかを印で見分けられる
````
